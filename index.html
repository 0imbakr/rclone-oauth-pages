Personal Backup Utility

A private, single-user application that copies its owner's own backup files to the owner's own Google Drive.

What it does

Once a day, the application packages a small set of files from its owner's computer into a single archive, encrypts that archive on the computer, and uploads it to the owner's Google Drive. It is run by one person, for their own files. There are no other users, and there is no service offered to anyone else.

What it can see

The application requests only the drive.file permission. That scope limits it to the files it creates itself — it cannot open, read or list anything else in the Drive account.

Encryption

Archives are encrypted before they leave the computer, using rclone's crypt layer. Both the file contents and the file names are encrypted. Nothing readable is stored remotely.
