Privacy Policy

Personal Backup Utility · last updated 1 October 2026

This application is operated by a single individual for their own personal use. It has no other users and offers no service to the public.

What data is accessed

The application uses Google Drive only to store backup archives that it creates itself. It requests a single permission, drive.file, which restricts it to files it has created. It cannot read, list or modify any other file in the Google Account.

What is uploaded

Encrypted archive files, generated on the operator's own computer from the operator's own files. Contents and file names are both encrypted before upload, so the stored data is not readable by anyone without the operator's key — including Google.

What is not done

  • No data is sold, rented, shared or disclosed to any third party.
  • No data is transferred to anyone other than Google Drive, acting as storage.
  • No analytics, advertising, tracking or cookies are used by this application or these pages.
  • No data from Google user accounts is used to develop, improve or train any artificial intelligence or machine learning model.
  • No data is collected from visitors to these pages.

Limited use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Archives are kept in the operator's own Google Drive and are deleted by the operator on their own schedule. Access can be withdrawn at any time from the Google Account's third-party access settings, which immediately stops any further upload.

Contact

Questions about this policy can be sent to the support address shown on the Google consent screen for this application.
